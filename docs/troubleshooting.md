# 故障排查

[文档首页](README.md) · [项目首页](../README.md)

## 看不到侧栏或命令

在启动 Jupyter 的环境运行 `jupyter labextension list` 和 `jupyter server extension list`，确认扩展为 enabled / OK。
确认使用 JupyterLab 4.2+ 或 Notebook 7.2+；经典 Notebook 6 不支持此界面。
升级后需要重启 Server 并刷新页面；只重启 Python 内核不会更新前端。
Notebook 7 可通过命令面板搜索 `DolphinDB: 管理连接`。扩展管理器搜索不到预发布包时使用 [pip 安装](installation.md)。

## 连接失败、超时或 SSL 错误

| 现象 | 检查方向 |
| --- | --- |
| 浏览器能访问数据库，但 DOS 无法连接 | 目标地址由 Jupyter Server 访问，检查该机器的网络和防火墙 |
| DOS 正常但 Notebook 无法连接 | 检查 Python 内核所在机器、官方 SDK 和 TCP / SSL 可达性 |
| `127.0.0.1` 在远程部署失效 | 它指连接发起机器自己；改成该机器可访问的 DolphinDB 地址 |
| 测试连接超时 | 检查 WebSocket 端口、SSL 和证书；侧栏超时只限制建立连接，不限制用户查询执行 |
| 保存后密码丢失 | 未勾选记住密码时，密码只在 Server 内存中，重启后重新输入 |
| keyring 不可用 | 解锁系统凭据库，或取消记住密码后使用当前 Server 生命周期内的密码 |
| 编辑同名配置后仍看到旧会话 | 已运行会话刻意保持连接快照；关闭该会话后再切换。未运行预览会跟随配置更新 |

配置文件不包含密码。自定义目录通过 `DolphinDBExtensionApp.connections_dir` 设置；手动 IPython 选择使用 `DOLPHINDB_CONNECTIONS_DIR`，两者场景不同，见 [连接说明](connections.md)。

## Notebook 提示找不到 `%ddb` 或内核扩展

在单元格中查看 `sys.executable`，确认该内核环境安装了相同版本的 `dolphindb-extension[notebook]`。
重启内核后再试；独立 IPython 可先运行 `%load_ext dolphindb_extension`。
工具栏支持 Python / IPython 内核，其他语言内核不会自动执行 Python 加载代码。

如果只有手动 `%ddb_connect` 失败，确认该进程能读取保存的配置和系统凭据库。Server 内存密码应通过 Notebook 工具栏传入。
普通 Python 单元格不需要可用 DDB 连接；不要为了显示普通 DataFrame 修改 DDB 配置。

## 输出组件与预期不同

- `a = %ddb ...` 后显示 `a` 使用 Python / pandas 原生组件，这是设计行为。
- 单元格最后直接写 `%ddb ...`，或无 `-o` 的 `%%ddb`，才自动显示 DDB 自定义组件。
- 需要显式展示时使用 `ddb_show(a)` 或 `%ddb_show a`；已有同名 Python 变量不会被自动覆盖，可自行导入函数。
- `%%ddb -o a` 只赋值；代码返回 `None` 不会生成自动结果组件。
- 没有安装前端的客户端、静态查看器或部分 Notebook 导出工具只能显示保存的回退文本，不能继续请求内核分页。

完整示例见 [Notebook 展示规则](notebooks.md)。

## 数据库或变量面板为空、提示不完整

第一次运行前变量面板为空；数据库面板只显示当前选定连接可见的资源。
正在执行时，动态元数据和预览可能暂不可用；内核变为 idle 后刷新。
检查当前激活的是哪个 DOS / Notebook、该会话是否已断开、账号是否有读取权限。
静态变量补全不要求运行代码，但动态表字段需要表在该会话中存在。

模块索引查找 Jupyter 文件，不负责上传至 DolphinDB。`use` 能补全但运行找不到模块时，检查服务端模块搜索路径。
外部修改的模块最多等待约 15 秒或运行 `DolphinDB: 刷新模块索引`。Notebook 中请将 `%%ddb` 放在单元格第一行。

## 缓存过期、历史省略或浏览器只排序一页

结果缓存有数量和内存预算；过期后重新执行并展示，或对仍保留的 Python 对象再次 `ddb_show`。
预算清理不删除 Python 返回变量或 DDB 会话变量。内核重启会丢失内核中的对象。
DOS 历史同样有限，超出帧预算时只能恢复保留部分。需要持久保存结果时自行导出数据。

表头排序只影响当前页，全表排序请用 DDB `order by` 或 Python `sort_values` / `sort_index`。
大变量悬浮只显示摘要时，可点击眼睛按钮打开数据浏览器，或调整变量预览字节上限。
三维曲面需要浏览器支持 WebGL；图表库已打包，故障时同时检查浏览器控制台及服务器返回的数据类型。

## 会话被锁定、断开或在另一页面使用

第一次提交代码后会固定连接，代码报错也算提交；更换连接应先关闭会话。
同一普通 DOS 会话不能同时被两个页面接管，可返回原页面使用或从 Running 面板关闭后重建。
网络真正断开时不会自动重放用户代码。关闭编辑器与关闭会话不同，具体见 [生命周期表](architecture.md)。

调试使用独立会话，不会自动继承普通执行会话中已创建的变量。
关闭最后一个 DOS 调试编辑器会停止调试；普通执行会话在关闭页面后仍由 Server 保留。

## 调试按钮或快捷键不可用

确认当前是 `.dos` 或其调试模块源码窗口，Notebook 不使用此 DOS 调试器。
确认服务端支持 debug WebSocket 协议及账号权限，先测试连接，再在有效代码行设断点。
F5 需要焦点位于代码编辑器；在工具栏、搜索框或浏览器界面中按 F5 可能执行环境自身的操作。
普通运行、连接建立或调试命令尚未完成时，对应调试操作会暂时禁用。

入口源码使用当前编辑内容，导入模块则来自服务器。模块更新后重新开始调试，旧模块窗口会关闭。
暂停后选择正确栈帧查看变量；暂不支持条件断点、监视表达式或变量赋值，详见 [调试边界](debugging.md)。

## 设置、布局和其他扩展

手动收起数据库与变量侧栏后，执行代码不会强制展开。使用右侧图标或文档工具栏的显示按钮打开。
数字显示位数只影响自定义组件，不修改 pandas 全局显示选项或原始对象。
Notebook 7 若没有 Settings Editor，可在共享设置目录的 JupyterLab 中修改，再刷新 Notebook。

本扩展通过 `INotebookCellExecutor` 替换默认执行器来排序自动配置请求。若另一扩展也替换该服务，需要选择一个提供者；禁用本扩展的执行器后不能依赖自动就绪屏障。

报告问题时附扩展版本、Jupyter / Python 版本、Server 与内核是否同环境、最小代码和相关错误。
连接密码、PyPI token、Jupyter 登录 token 不应出现在日志截图或公开 issue 中。
